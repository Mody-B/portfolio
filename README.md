# Mohamad Bitar — Portfolio

**Lumen** motion-first AI engineering portfolio. Custom domain: **mohamadbit.me**.

## Easiest way onto GitHub (no CLI)

1. Create empty **public** repo **`portfolio`** under **Mody-B**: https://github.com/new  
2. Download **`portfolio-for-github.zip`** from Project Context media  
3. Unzip → on the empty GitHub repo click **uploading an existing file** → drag the folder **contents** → commit to **main**

Full browser steps: Project doc `docs/github-com-setup.md`.

## Local development

```bash
npm install
npm run dev -- --port 4321
```

## GitHub Pages + `mohamadbit.me`

- `public/CNAME` is already `mohamadbit.me`
- After upload: **Settings → Pages** → Source **GitHub Actions** → custom domain `mohamadbit.me`
- DNS: apex A → `185.199.108–111.153`; www CNAME → `Mody-B.github.io`
